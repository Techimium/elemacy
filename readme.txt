Elemacy is a WordPress plugin to extend Elementor with powerful widgets and features.

== Description ==

Elemacy is a WordPress plugin to extend elementor. It provides a variety of widgets and features to enhance your page building experience.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/elemacy` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the Elemacy menu to configure the plugin.

== Frequently Asked Questions ==

= Does this require Elementor? =

Yes, Elemacy is an extension for Elementor and requires it to be active.
