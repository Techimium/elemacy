### 🎨 Theme Builder

Take complete control of every part of your WordPress theme using Elementor's drag-and-drop editor.

**Build custom templates for:**

* **Header** – Design a pixel-perfect header with full Elementor support. Replace your theme's default header entirely.
* **Footer** – Create a custom footer with widgets, menus, social links, and anything Elementor supports.
* **Single Post / Page** – Design a unique layout for individual posts, pages, or any custom post type.

### 🔁 Loop Builder Widget

Display any post type — including custom post types — in a dynamic, fully customizable grid or carousel. No coding required.

**Loop Grid Features:**

* Select any Elementor template as the loop item design
* Choose any public post type as your data source (including custom post types)
* Query builder: control posts per page, offset, order by (date, title, menu order, random), and sort direction (ASC/DESC)
* Exclude the current post from the loop automatically
* Built-in **AJAX Pagination** — page through results without a full page reload
* Pagination styles: Numbers, Previous/Next, or Numbers + Previous/Next
* Responsive column control (1–12 columns, per device breakpoint)
* Responsive column gap and row gap controls
* Full pagination styling: colors (normal/hover/active), typography, border, border-radius, padding

**Loop Carousel Features:**

* All the power of the Loop Grid in a smooth, swipeable carousel format
* Ideal for testimonials, product showcases, team members, and more

### 📋 Form Builder Widget

Build fully custom contact forms — or any kind of form — directly inside Elementor. No third-party form plugin needed.

**Supported Field Types:**

* Text
* Email
* Textarea
* Telephone
* Select (dropdown)
* Radio buttons
* Checkbox

**Form Configuration:**

* Drag-and-drop field ordering with repeater control
* Set each field's label, placeholder, required status, and column width (20%–100%)
* Show or hide field labels
* Custom field IDs for advanced use in email templates
* Configurable option lists for Select, Radio, and Checkbox fields

**Actions After Submit:**

* **Email Notification** – Send form submissions directly to any email address(es). Configure the To, Subject, Message body (with `[all-fields]` shortcode or specific `[field_id]` placeholders), From Name, From Email, and Reply-To address.

**Full Styling Controls:**

* Form layout: column gap, row gap
* Label: spacing, color, typography
* Input fields: text color, placeholder color, typography, background, border, border radius, padding
* Submit button: typography, normal/hover colors, border, border radius, box shadow, padding
* Success/error messages: spacing, typography, border type, border width, border radius, and more

> **⚡ Coming Soon:** Form submission storage — save every form submission to your WordPress database and view them in the admin dashboard.

### 🏷️ Dynamic Tags

Make your Elementor designs truly dynamic. Use real data from your WordPress site anywhere a dynamic field is supported in Elementor.

**Post Dynamic Tags:**

* **Post Title** – Output the current post's title
* **Post URL** – Link to the current post
* **Post Content** – Display the full post content
* **Post Excerpt** – Display the post excerpt
* **Post Date** – Show the publication date (with format control)
* **Post Featured Image** – Use the featured image as a dynamic image source
* **Post Custom Field** – Pull data from any WordPress custom field (meta)

**Site Dynamic Tags:**

* **Site Title** – Your WordPress site name
* **Site Tagline** – Your site's tagline/description
* **Site URL** – Your site's homepage URL
* **Site Logo** – Your site's logo image

**Advanced Custom Fields (ACF) Dynamic Tags:**

* **ACF Text/Field** – Render any ACF text-based field
* **ACF Image** – Use an ACF image field as a dynamic image source
* **ACF Gallery** – ACF gallery field support
* **ACF Color** – Output ACF color picker values
* **ACF Date/Time** – Display ACF date and datetime picker values
* **ACF Number** – Output ACF number fields
* **ACF URL** – Use ACF URL fields as dynamic links

> **⚡ Coming Soon:** More dynamic tags including user data, WooCommerce product fields, taxonomy terms, and more.

### 🎯 Custom CSS Control

Write custom CSS for any Elementor widget, section, column, or page — right inside the Elementor panel. No child theme required.

* Adds a **Custom CSS** tab to the Advanced panel of every Elementor element
* Use the `selector` keyword to automatically target the specific element's unique CSS class
* Also available at the **Page Settings** level for page-specific styles
* CSS is compiled and injected into Elementor's generated stylesheet — no render-blocking inline styles
* Perfect for fine-tuned adjustments beyond what visual controls allow

== Installation ==

**Automatic Installation (Recommended)**

1. Log in to your WordPress admin dashboard.
2. Navigate to **Plugins → Add New**.
3. Search for **"Elemacy"**.
4. Click **Install Now**, then **Activate**.

**Manual Installation**

1. Download the plugin ZIP file.
2. Log in to your WordPress admin dashboard.
3. Navigate to **Plugins → Add New → Upload Plugin**.
4. Upload the ZIP file and click **Install Now**.
5. Click **Activate Plugin**.

**After Activation**

1. Make sure **Elementor** is installed and activated.
2. Navigate to **Elemacy** in your WordPress admin menu.
3. Enable the modules you need from the Modules management page.
4. Start building with Elementor — all Elemacy widgets and features will appear automatically.

== Frequently Asked Questions ==

= Does Elemacy require Elementor Pro? =

No. Elemacy works with the **free version of Elementor**. You do not need Elementor Pro to use any of Elemacy's features.

= Is Elemacy really 100% free? =

Yes. Every feature described in this listing is completely free. There are no premium tiers, upsells, or feature locks. Elemacy is open source software released under the GPLv2 license.

= Will Elemacy slow down my website? =

Elemacy is built with performance in mind. It uses a modular architecture — you can disable any module you don't need from the admin dashboard, ensuring no unnecessary code is loaded on your site.

= Does the Theme Builder work with any WordPress theme? =

Yes. The Elemacy Theme Builder is designed to work with any WordPress theme. It hooks into the standard WordPress template system to override headers, footers, and content templates — theme-agnostically.

= Does the Loop Builder require any special setup? =

To use the Loop Builder, you need to first create a **Loop template** using the Theme Builder (select "Loop" as the template type). Then assign that template inside the Loop Builder widget. The Loop template is used to design each individual item (card) in your loop.

= Can I use ACF dynamic tags without ACF installed? =

No. The ACF dynamic tags require the **Advanced Custom Fields** plugin (free version from WordPress.org works fine) to be installed and active. If ACF is not installed, the ACF tags will simply not appear.

= What field types does the Form Builder support? =

Currently: Text, Email, Textarea, Telephone, Select (dropdown), Radio buttons, and Checkbox. More field types are planned for future releases.

= Does the Form Builder store submissions? =

The current version sends form submissions via email. **Form submission storage** (saving entries to the WordPress database) is on the roadmap and will be added in a future release.

= Can I contribute to Elemacy? =

Absolutely! Elemacy is open source. Visit our GitHub repository (link in the plugin description) to report issues, submit pull requests, or propose new features.

= Where can I get support? =

Use the official WordPress.org support forum for this plugin. For bug reports and feature requests, you can also open an issue on our GitHub repository.

= Is Elemacy compatible with WooCommerce? =

Partial support is included. The Theme Builder automatically detects the WooCommerce Shop page when determining which archive template to apply. Full WooCommerce widget support is planned for future versions.
